# Práctica 02 - Construcción de la red simulada en GNS3
 
En esta práctica se construyeron y configuraron dos topologías de red utilizando GNS3.
 
## Topología 1
 
Se configuró una red formada por dos VPCS y un switch Ethernet, asignando direcciones IP y realizando pruebas de conectividad.
 
## Topología 2
 
Se configuró una red formada por dos routers Cisco IOSv y un switch Cisco IOSvL2. Se configuró direccionamiento IP, interfaces Loopback y el protocolo OSPF.
 
## Resultados
 
Se comprobó la conectividad entre los dispositivos mediante ping, vecinos OSPF y la tabla de enrutamiento.
